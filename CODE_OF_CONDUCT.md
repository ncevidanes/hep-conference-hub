# Código de Conduta

Este projeto busca um ambiente respeitoso, colaborativo e tecnicamente
rigoroso. Participantes devem tratar outras pessoas com respeito, aceitar
críticas fundamentadas, citar fontes corretamente e evitar assédio,
discriminação, intimidação ou exposição de dados pessoais.

Comportamentos incompatíveis podem resultar em remoção de conteúdo,
restrição de participação ou bloqueio, conforme avaliação do mantenedor.
