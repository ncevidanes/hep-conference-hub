# Como contribuir

1. Abra uma issue descrevendo o problema, a fonte oficial ou a melhoria.
2. Crie uma branch curta a partir de `main`.
3. Mantenha cada arquivo e módulo com responsabilidade clara.
4. Acrescente testes para correções e novos extratores.
5. Não publique prazos sem URL e evidência verificável.
6. Execute a suíte Python e o build do frontend.
7. Abra um pull request explicando impacto, fonte e estratégia de validação.

## Padrões de commit

Sugestões:

- `feat: adiciona coletor para nova fonte`
- `fix: corrige cálculo do status de inscrição`
- `docs: atualiza documentação de implantação`
- `test: cobre conflito entre datas oficiais`

## Dados pessoais e segredos

Nunca envie `.env`, tokens, senhas, listas de e-mail ou dados pessoais de
assinantes para o repositório.
