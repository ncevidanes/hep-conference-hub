# HEP Conference Hub 1.0.0

Primeira release pública do HEP Conference Hub.

## Destaques

- pesquisa e filtragem de eventos científicos em HEP/HECAP;
- estado temporal de eventos calculado separadamente da submissão;
- fases independentes de inscrição;
- páginas funcionais de submissão, registro, programa e proceedings;
- evidências auditáveis, confiança e data de verificação;
- catálogo e descoberta de eventos latino-americanos;
- API REST, portal web, crawler e execução por Docker Compose;
- documentação técnica completa em PDF e LaTeX.

## Validação

Antes da publicação, execute:

```bash
bash scripts/pre_release_check.sh
```

## Nota sobre dados

As fontes externas permanecem sob responsabilidade de seus provedores. O
software registra evidências e divergências, mas a publicação de oportunidades
deve continuar sujeita a validação editorial.
